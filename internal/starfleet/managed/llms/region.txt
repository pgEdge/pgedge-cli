### pgedge starfleet managed region

Discover the regions a managed database can be created in.

These are the accepted values for `database create --region`. The region
is the whole of a managed database's placement decision.

**Example:**

```bash
pgedge starfleet managed region list
```

#### pgedge starfleet managed region list

List every region a managed database can be created in.

Expected: a single-column REGION table, or the raw array under
`-o json`/`-o yaml`. The API answers with objects rather than bare
strings, so a json consumer reads `.[].region`.

**Example:**

```bash
pgedge starfleet managed region list
pgedge starfleet managed region list -o json
```
