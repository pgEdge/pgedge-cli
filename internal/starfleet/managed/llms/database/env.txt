###### pgedge starfleet managed database env pull

**Usage:** `pgedge starfleet managed database env pull [<database_id>] [flags]`

Write DATABASE_URL for a database into .env

**Flags:**

| Flag | Required | Default | Description |

| `--var string` | No | `DATABASE_URL` | Variable name to set |

##### pgedge starfleet managed database env pull

Set `DATABASE_URL` in a `.env` file to the database's connection URI,
and leave every other line of the file as it was. The last line
assigning the variable is replaced, keeping an `export` prefix;
without one the line is appended. A missing file is created at mode
0600, and an existing file keeps its mode. A file that is a symbolic
link is exit 1 and is not written. A `--var` that is not a variable
name is exit 2, before any request.

With no ID the folder's link names the database, or its branch when
the link names one, and the file is `.env` beside the `.pgedge`
folder. With an ID the file is `.env` in the current folder. `--file`
names another file, `--var` another variable, and `--user-type` picks
the role, admin, app or app_read_only, app by default.

The value holds the role's live password. Every byte outside the URI
unreserved set is percent-encoded, `$` and `#` included, so the value
is written unquoted and a loader that expands `$NAME` reads it
unchanged. stdout stays empty. On stderr, a line beginning `Set`
names the variable, the file, the database or branch and the role;
with no ID it follows a `Using database <id> from <path>` line. Inside a git work tree, a file git does not ignore
adds a warning naming the `.gitignore` line to add. A database with no
connection host yet is exit 1 and writes nothing.

**Example:**

```bash
pgedge starfleet managed database env pull
```
