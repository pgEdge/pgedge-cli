###### pgedge starfleet byoc database env pull

**Usage:** `pgedge starfleet byoc database env pull <database_id> [flags]`

Write DATABASE_URL for a database node into .env

**Flags:**

| Flag | Required | Default | Description |
|------|----------|---------|-------------|
| `--file string` | No | `.env` | File to write |
| `--internal` | No |  | Use the node's internal_host, for a client inside the cluster |
| `--node string` | No |  | Node whose connection to write (required with several nodes) |
| `--var string` | No | `DATABASE_URL` | Variable name to set |

##### pgedge starfleet byoc database env pull

Set `DATABASE_URL` in a `.env` file to one node's connection URI, and
leave every other line of the file as it was. The last line assigning
the variable is replaced, keeping an `export` prefix. Without one, the
line is appended. A missing file is created at mode 0600, and an
existing file keeps its mode. A file that is a symbolic link ends with
exit status 1 and is not written. A `--var` that is not a variable
name ends with exit status 2, before any request.

The file is `.env` in the current folder. `--file` names another file,
and `--var` another variable. The argument takes a full UUID.

The node is chosen as `database connection-string` chooses it. With
one node no flag is needed. With several, `--node <name>` picks one,
by the node's `name` or its `logical_name`. Without `--node`, the
command prints the node table on stdout and writes no file. The table
has the columns NODE, NAME, HOST, INTERNAL HOST and PORT, and no
credential. The command then ends with exit status 2, naming the flag.
`--internal` builds the URI from the node's `internal_host`, for an
application inside the cluster's network. A node that has only the
other host ends with exit status 1, naming the flag that would reach
it.

The value holds the role's live password. Every byte outside the URI
unreserved set is percent-encoded, `$` and `#` included. The value is
therefore written unquoted, and a loader that expands `$NAME` reads it
unchanged. Apart from the node table, stdout stays empty. On stderr, a
line beginning `Set` names the variable, the file, the node, the
database and the role.

Inside a git work tree, a file git does not ignore adds a warning
naming the `.gitignore` line to add. A file git already tracks adds a
warning naming `git rm --cached` as well, because ignoring it alone
keeps committing the password. A node with no connection host yet
ends with exit status 1, and no file is written.

**Example:**

```bash
pgedge starfleet byoc database env pull f6a7b8c9-d0e1-2345-fabc-456789012345 \
    --node n1 --file .env.local
```
